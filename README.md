# VRChat 视频解析器

> 一个 Edge 浏览器扩展：从网页提取视频**直链**，一键复制粘贴到 **VRChat 视频播放器** 里播放。

## ✨ 功能特性

- 🔍 **自动嗅探**：监听页面网络请求 + 主世界拦截 `fetch`/`XHR`，双保险捕获媒体地址（自动过滤只有几秒的 `.ts` / `.m4s` 分片）
- 🎯 **智能去重**：每个视频默认只显示**一条**结果，同一视频的多个 CDN 节点用下拉框切换
- 📺 **Bilibili 解析**：视频页 / 番剧页直接出直链，采用 [bilibili-parse](https://github.com/injahow/bilibili-parse)（MIT）的 `platform=html5` 方案，**免 Referer 的直链排在最前**
- 🎚 **登录与画质**：可查看 B 站登录状态、选择目标画质（1080P / 720P60 / 720P / 480P），请求走带登录 Cookie 的通道
- 🎬 **1080P 合并**：B 站 1080P 只存在于 DASH 通道（音视频分离），插件会自动抓取并给出**一键复制的 ffmpeg 合并命令**
- 🎯 **直链探测**：对无法判断格式的链接自动发 `Range: bytes=0-1` 请求，识别**真实类型与体积**，一眼看出哪条「完整文件」适合分享
- 🔁 **中转服务**：可配置自建 Cloudflare Worker（如 bili-resolver）作为 B 站解析源，彻底绕开 Referer 403
- 🎬 **HLS 站点支持**：动漫站等 m3u8 站点会给出 ffmpeg 合并命令，转成 MP4 后即可分享给所有人
- 🌫 **毛玻璃 UI**：极光动态背景、列表错峰入场、复制脉冲、扫描转圈等动画
- 🔒 **纯本地运行**：无任何服务器，不收集、不上传任何数据
- 📚 **B 站分P 解析**（v2.0.0 新增）：多 P 视频会在顶部列出**全部分P**（标题 + 时长），可单独解析某一 P，也可「⚡ 解析全部分P」批量出链接，每条结果都带 `P2 · 标题` 标记
- 🔴 **直播解析**（v2.0.0 新增）：B 站直播走官方接口（免登录拿原画 FLV）；斗鱼 / 虎牙 / 抖音 / 快手 / Twitch 用「网络嗅探 + 页面源码抓取」拿到直播流，并给出**转推 / 录制**命令

> 详细的功能说明、常见问题与图文教程见 [`docs/`](docs/) 目录。

## 📦 安装

要求：**Windows 版 Microsoft Edge 111 或更高版本**

### 方式一：克隆本仓库后加载（推荐）

```bash
git clone https://github.com/Enkozy/vrchat-video-parser.git
```

1. Edge 地址栏输入 `edge://extensions/`
2. 打开左下角 **「开发人员模式」**
3. 点击 **「加载解压缩的扩展」**，选择**本仓库根目录**（能看到 `manifest.json` 的那一层）
4. 工具栏出现紫色 ▶ 图标，建议点「固定」

### 方式二：下载 ZIP

点本页右上角 **Code → Download ZIP**，解压后按上面的 3、4 步加载。

### 方式三：使用发布包

直接下载：[VRChat-Video-Parser-v1.9.2.zip](https://github.com/Enkozy/vrchat-video-parser/releases/download/v1.9.2/VRChat-Video-Parser-v1.9.2.zip)

## 🎮 使用方法

1. 打开视频网页（B 站打开视频页即可；其他网站建议先播放几秒）
2. 点击工具栏上的插件图标
3. 列表里 **绿色 ✅** 的条目就是可用直链：点「复制」，或直接点该条目
4. 进入 VRChat → 打开视频播放器 → 粘贴到 URL 栏 → 播放

也可以点「📋 复制首选可用链接」一键复制最合适的那条。

### 📚 多 P 视频（分P）怎么用

打开 B 站多 P 视频页后，弹窗顶部会出现 **分P 面板**：

1. 面板列出 `P1 / P2 / P3…` 的标题与时长，**当前播放的那一 P 高亮**
2. 点某一行的 **「解析」** → 只解析这一 P，结果带 `P2 · 1080P 高清` 标记
3. 点 **「⚡ 解析全部分P」** → 依次解析（最多 20 个，够用且不容易触发风控）

> 每个分P 的直链彼此独立：复制哪一条就播哪一 P，`P1` 与 `P2` 的链接不能互换。

### 🔴 直播怎么用

直播流通常是 **FLV / HLS**，VRChat 播放器**不认**，所以要先把流转成它能吃的地址。插件会给三条命令，任选其一：

| 方案 | 按钮 | 适用 |
| --- | --- | --- |
| 转推到 Twitch / YouTube | `⚙️ 复制转推命令` | 想让大家**实时一起看**（推荐） |
| 自建 RTMP 中继 | 同上，把推流地址换成自己的 | 有服务器、想自己掌控 |
| 录成 MP4 | `📹 复制录制命令` | 只放一段，或事后分享 |

- **B 站直播**：打开房间页即可，插件自动走官方 `playUrl` 接口（免登录，多线路可选）
- **斗鱼 / 虎牙 / 抖音 / 快手**：先让直播画面跑起来（等 2~3 秒），再点「🔄 扫描」——流地址由播放器动态签发，必须有网络请求才能抓到

> 转推示例（复制后把 `<你的串流密钥>` 换成自己的 Twitch 密钥）：
>
> ```bash
> ffmpeg -headers "Referer: https://www.douyu.com/" -user_agent "Mozilla/5.0" \
>   -i "<直播流地址>" -c copy -f flv "rtmp://live.twitch.tv/app/<你的串流密钥>"
> ```
>
> 推流成功后，把 `https://www.twitch.tv/你的频道` 粘进 VRChat 播放器即可一起看。

## 📊 画质与兼容性速查

| 场景 | 结果 |
| --- | --- |
| B 站 · 未登录 | ≤ 480P |
| B 站 · 已登录免费账号 | **720P**（单文件 MP4 通道的接口上限） |
| B 站 · 需要 1080P | 只有 DASH 通道有（音视频分离）→ 用插件给出的 **ffmpeg 合并命令**转成 MP4 |
| YouTube | VRChat 原生支持，直接复制视频网址即可 |
| 动漫站 / HLS（m3u8） | VRChat 不能直接播；用 ffmpeg 合并成 MP4 后上传公开直链 |
| 优酷 / 腾讯 / 爱奇艺 | 加密分片，通常拿不到可直连的地址 |
| B 站 · 多 P 视频 | 分P 面板单独或批量解析，每 P 一条独立直链 |
| B 站 · 直播 | 官方接口直出 FLV 多线路 → 需转推 / 录制 |
| 斗鱼 / 虎牙 / 抖音直播 | 播放器签发的 FLV / M3U8 → 需转推 / 录制（插件给命令） |

## ❓ 常见问题

- **为什么「我能看，朋友看不了」？**
  VRChat 只同步链接，视频由**每个客户端各自下载**。这类链接常有 IP 绑定与短时效，朋友换网络可能能看但不稳定。要分享请用「完整文件」条目，或合并成 MP4 上传公开直链。
- **插件会把视频下载到我电脑里吗？**
  不会。探测只取 2 个字节读取响应头；VRChat 播放是内存缓冲；**只有你运行 ffmpeg 合并命令时**才会生成文件。
- **列表里的 `LINK` 是什么？**
  无法从后缀判断格式的直链，通常是**整段视频文件**，插件会自动探测出真实类型与体积并标注「可分享给别人」。
- **B 站链接过一会儿就失效？**
  B 站直链约 2 小时过期，回视频页「🗑 清空」→「🔄 扫描」重新获取即可。
- **为什么直播流不能直接粘进 VRChat？**
  直播是 FLV / HLS 这种「边下边播」的流，VRChat 播放器只认完整视频文件与 YouTube / Twitch 页面。所以直播要先**转推**（推成 Twitch / YouTube 直播）或**录制**成 MP4，这两步的命令插件会直接给。
- **「解析全部分P」会解析全部吗？**
  最多解析前 20 个分P（防止一次请求太多被 B 站限流）；分P 更多时可以先单独解析你要的那几个。

更多问题见 [`docs/安装与使用说明.txt`](docs/安装与使用说明.txt)。

## 🔧 工作原理

1. **网络嗅探**：后台 `webRequest` 监听媒体响应；`inject.js` 在页面主世界安全改写 `fetch` / `XHR`（失败则静默降级），双保险捕获地址
2. **B 站解析（三层）**：`platform=html5` 免 Referer 直链 → 普通接口多 CDN 节点 → 公共解析服务兜底
3. **1080P 合并**：检测到目标画质高于单文件通道上限时，额外请求 DASH 通道，挑选 ≤1080P 的 H.264 视频流 + AAC 音频流，生成 ffmpeg 合并命令
4. **结果呈现**：按标签页存储，按视频分组折叠，自动探测未知链接的类型与体积
5. **分P（v2.0.0）**：`x/web-interface/view` 拿 `pages[]`（标题 / cid / 时长）→ 后台缓存 → 弹窗渲染面板；每个分P 用**自己的 cid** 单独请求 `playurl`，所以链接互不干扰
6. **直播（v2.0.0）**：B 站直播 `room_init` → `Room/playUrl` 直出 FLV 多线路；其他平台由 `webRequest` 嗅探 + 页面源码正则（还原 `\u002F`、`\/` 转义）抓流，并按「域名 + 路径」去重，避免签名换一次就多一条

## 📁 项目结构

```
.
├── manifest.json          # 扩展清单（MV3）
├── background.js          # Service Worker：嗅探、探测、B站兜底请求、存储
├── inject.js              # 主世界注入：安全改写 fetch / XHR / history
├── content.js             # 内容脚本：DOM 扫描、B 站三层解析、消息桥接
├── popup.html / css / js  # 弹窗界面与逻辑
├── icons/                 # 图标
├── tools/                 # 一键合并脚本（ffmpeg）
├── docs/                  # 使用说明、发布文案、更新日志

```
