【简介 / 置顶文案】

大家好，我是知音illya 👋
做了个 Edge 浏览器插件「VRChat 视频解析器」，解决一个很烦的问题：
网页视频没法直接丢进 VRChat 的播放器里。

✨ 主要功能
· B 站视频 / 番剧一键解析，自动给出可直接播放的直链（免 Referer 优先）
· 同一视频的多个 CDN 节点用下拉框切换，并显示链接有效期，失效一眼看出
· 显示 B 站登录状态，可选目标画质（720P / 1080P）
· 想要 1080P：自动抓取 DASH 视频流 + 音频流，一键复制 ffmpeg 合并命令
· 其他网站通吃：MP4 / WebM 直链、动漫站的 HLS 切片流都能处理
· 自动探测链接的「真实类型 + 体积」，一眼看出哪条适合分享给别人
· 毛玻璃界面 + 动画，不是上古 UI 😄
· 纯本地运行，无任何服务器，不收集数据，源码完全公开可查

📥 下载地址
· GitHub 开源仓库（欢迎 Star ⭐）：https://github.com/<你的用户名>/vrchat-video-parser
· 网盘整合包（含一键合并工具与图文说明）：<网盘链接>　提取码：<xxxx>

📦 安装步骤
1. 解压到固定目录（建议 D 盘，解压后别再移动）
2. Edge 打开 edge://extensions/ → 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」→ 选择 vrchat-video-parser 文件夹
4. 工具栏出现紫色 ▶ 图标即安装成功

⚠️ 使用须知
· 仅支持 Windows 版 Edge 111+
· B 站单文件直链上限是 720P，1080P 需要用包内的 ffmpeg 合并流程
· 动漫站 / 网盘类链接常有 IP 绑定与短时效，适合自己看；
  要分享给房间里的朋友，请合并成 MP4 后上传到公开直链空间
· 本工具仅供个人学习交流，请勿用于商业用途；内容版权归原权利人所有
