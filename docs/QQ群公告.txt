【一、本群是做什么的】
本群是 Edge 插件「VRChat 视频解析器」的使用交流与反馈群：
· 插件下载 / 更新通知
· 安装、使用问题答疑
· B 站、动漫站等视频在 VRChat 里播放的排查
· 观影搭子、VRChat 世界推荐（欢迎闲聊）

【二、插件获取与安装】
🔗 开源仓库（欢迎 Star ⭐）：https://github.com/Enkozy/vrchat-video-parser
💾 下载：GitHub Releases / 群文件 / 网盘
📦 当前版本：v1.9.2

安装步骤（3 分钟）：
1. 解压到一个固定目录（建议 D 盘，解压后不要再移动）
2. Edge 地址栏输入 edge://extensions/　回车
3. 打开左下角「开发人员模式」
4. 点「加载解压缩的扩展」→ 选择解压目录里的 vrchat-video-parser 文件夹
5. 工具栏出现紫色 ▶ 图标即安装成功（建议点「固定」）

更新方法：用新版文件覆盖旧目录 → 回 edge://extensions/ 点「重新加载」

【三、提问前必看：4 个高频问题】
1. B 站为什么只有 720P？
   B 站把 1080P 放在 DASH 通道（音视频分开），单文件直链的接口上限就是
   720P，不是插件的问题。想要 1080P：解析后点弹窗顶部的
   「⚙️ 复制 1080P 合并命令」，用 ffmpeg 合并成 MP4（教程在群文件）。
2. 我能看，为什么别人看不了？
   VRChat 只同步「链接」，视频是每个客户端各自下载的。动漫站/网盘类链接
   常有 IP 绑定和短时效，别人换个网络可能能看但不稳定。要分享请用列表里
   标着「完整文件 xxMB」的绿色条目，或合并成 MP4 上传到公开直链空间。
3. 插件会把视频下载到我电脑里吗？
   不会。探测只取 2 个字节读响应头；VRChat 播放是内存缓冲；只有你自己运行
   ffmpeg 合并命令时才会生成文件。
4. 链接过一会儿就失效？
   B 站直链约 2 小时过期。回视频页点「🗑 清空」→「🔄 扫描」重新获取即可。

【四、反馈问题的正确姿势】
在插件弹窗点「🩺 复制诊断信息」→ 把结果粘贴到群里。
里面包含版本号、页面地址、各条链接的类型/体积/节点/有效期，
有了它我基本能直接定位问题；只发截图或"看不了"三个字会比较难排查。
