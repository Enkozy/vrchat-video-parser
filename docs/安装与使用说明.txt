 VRChat 视频解析器  v1.9.1
 作者 / 发布人：知音illya
==================================================

【这是什么】
一个 Edge 浏览器插件：把网页上的视频提取成「直链」，复制后粘贴到
VRChat 视频播放器里播放。重点支持 B 站（视频 / 番剧），同时也能处理
其他网站的 MP4/WebM 直链、以及动漫站的 HLS 切片流。

【支持环境】
Windows 版 Microsoft Edge 111 或更高版本（版本过低可能无法加载）。

--------------------------------------------------
一、安装（3 分钟）
--------------------------------------------------
1. 把压缩包解压到一个固定目录，建议 D 盘，例如：
      D:\VRChat解析器\
   ⚠️ 解压后不要再移动或删除该目录，否则插件会失效。
2. 打开 Edge，地址栏输入：edge://extensions/   然后回车
3. 打开左下角（或左侧）的「开发人员模式」开关
4. 点击「加载解压缩的扩展」
5. 选择解压目录里的 vrchat-video-parser 文件夹（里面能看到 manifest.json）
6. 工具栏会出现紫色 ▶ 图标 → 建议点「固定」把它放到工具栏上

--------------------------------------------------
二、基本用法
--------------------------------------------------
1. 打开视频网页
   · B 站：打开视频页即可（不用播放）
   · 其他网站：建议先播放几秒，让插件抓到地址
2. 点击工具栏上的插件图标
3. 列表里「绿色 ✅」的条目就是可用直链：
   · 点条目右侧的「复制」，或直接点整条
   · 也可以点顶部「📋 复制首选可用链接」一键复制最合适的那条
4. 进入 VRChat → 打开世界里的视频播放器 → 粘贴到 URL 栏 → 播放

--------------------------------------------------
三、B 站特别说明
--------------------------------------------------
· 未登录：一般只能拿到 480P 以下
· 已登录（免费账号）：单文件直链最高 720P
· B 站的 1080P 只存在于 DASH 通道（音视频分开存放），
  单文件直链通道的接口上限就是 720P —— 这不是插件的问题
· 想要 1080P：解析后弹窗顶部会出现蓝色提示横幅，
  点「⚙️ 复制 1080P 合并命令」，用 ffmpeg 把视频流+音频流合并成 MP4
  （ffmpeg 安装命令也在横幅上，一键复制；包内 tools 文件夹还有
   「一键合并.cmd」可以全自动完成）
· B 站直链约 2 小时过期，失效了就回视频页点「🗑 清空」→「🔄 扫描」

--------------------------------------------------
四、动漫站 / HLS 站点说明
--------------------------------------------------
· 这类站点用 m3u8 切片，VRChat 播放器不支持直接播放
· 你自己可能能播（链接往往绑定你的 IP），但别人通常播不了
· 插件顶部会给出「⚙️ 复制 ffmpeg 合并命令」→
  合并成 MP4 后上传到公开直链空间（推荐 Cloudflare R2 免费桶），
  这样房间里所有人都能看，Quest 一体机也能播

--------------------------------------------------
五、常见问题
--------------------------------------------------
Q：列表里标着 LINK 的是什么？
A：插件无法从链接后缀判断格式的直链，通常其实是「整段视频文件」。
   插件会自动探测它的真实类型和体积：
   · 显示「完整文件 xxxMB · 可分享给别人」→ 这条最稳，别人也能播
   · 显示「疑似分片」→ 只有几秒，不要用

Q：为什么我能看，朋友看不了？
A：VRChat 只同步「链接」，视频是每个人各自去下载的。
   这类链接常有 IP 绑定和时效：朋友换个网络/挂梯子可能能看，但不稳定。
   要分享就用「完整文件」那条，或合并成 MP4 上传到公开直链。

Q：插件会不会偷偷把视频下载到我电脑里？
A：不会。插件只做「读取地址」和「探测响应头」（只取 2 个字节），
   不下载视频内容。只有你自己运行 ffmpeg 合并命令时才会生成文件。

Q：插件安全吗？会收集数据吗？
A：全部在浏览器本地运行，没有任何服务器，不上传任何数据。
   源代码完全公开（包内就是全部源码），可以自行审查。
