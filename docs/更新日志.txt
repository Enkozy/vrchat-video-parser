v2.0.1（分P 修复版）
· 分P 按钮合并为「解析+复制」：点一次就解析，成功后自动把最佳链接
  （免 Referer 主链优先）放进剪贴板，不用再点第二次「复制」
· 修复「只能解析第一个分P，切到第二个分P解析不了」
  原因：分P 列表只从 view 接口取，接口被风控（-412 等）时就拿不到列表，
        于是回退到「页面状态里的 cid」——而 B 站切换分P 时 __INITIAL_STATE__
        里的 cid 仍停在打开页面时那一 P，结果永远解析到 P1
  修复：优先读页面自带的 __INITIAL_STATE__.videoData.pages（零请求、不受风控影响），
        URL 的 ?p= 优先于页面状态，接口只作为「更全时」的补充
· 修复「点了解析没反应/显示已解析但没结果」：现在会明确报错
  - 接口返回非 0（如 87008 充电专属、-412 风控、-10403 地区限制）直接提示 code
  - 「解析全部分P」结束时汇总：成功 X / 失败 Y（附前两条失败原因）
· 新增画质降级链：目标画质失败自动降到 720P / 480P 再试
· 诊断信息新增分P条目（数量、当前 P、各分P 的 cid）
· 版本号 2.0.1

v2.0.0（分P + 直播）
· 新增「B 站分P解析」：多 P 视频弹出分P面板，列出全部分P（标题 + 时长）
  - 单个分P独立解析，结果带「P2 · 1080P 高清」标记
  - 支持「解析全部分P」，一次最多 20 个（防限流）
  - URL 的 ?p= 优先于页面状态，SPA 切换分P也能对上
· 新增「直播解析」
  - B 站直播：room_init → 官方 playUrl，免登录拿原画 FLV 多线路
  - 斗鱼 / 虎牙 / 抖音 / 快手 / Twitch：网络嗅探 + 页面源码抓流，
    直播流按「域名+路径」去重（签名刷新不再刷屏）
  - 新增红色直播横幅：一键复制直播流地址 / ffmpeg 转推命令 / 录制命令
· 解析失败提示改进：区分「不是视频页」与「没找到该分P」
· 版本号改为与 manifest 同步显示
