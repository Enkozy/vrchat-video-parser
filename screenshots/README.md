# 截图目录

把你的截图放在这里，README 顶部的截图表格会自动引用。

建议补充 3 张：

1. `popup.png` —— 插件弹窗的解析结果列表（绿色条目 + 节点下拉框）
2. `bilibili-1080p.png` —— B 站页面上的蓝色「1080P 合并」提示横幅
3. `vrchat.png` —— 在 VRChat 视频播放器里粘贴链接后播放的画面

添加后在根目录 `README.md` 的「📸 截图」表格里把 `_待补充_` 换成图片引用，例如：

```markdown
| ![弹窗](screenshots/popup.png) | ![1080P](screenshots/bilibili-1080p.png) | ![VRChat](screenshots/vrchat.png) |
| --- | --- | --- |
| 弹窗解析结果 | B 站 1080P 提示 | VRChat 中播放 |
```
